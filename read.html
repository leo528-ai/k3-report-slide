K3 到底是什么
"把预训练底座扩到 3T 级参数，同时在 100 万上下文上扩展推理和长程交互——两条扩展轴一起推向前沿。"
整体落后最强闭源（Claude Fable 5 / GPT-5.6 Sol），但稳定领先其余所有开源与闭源模型。而且——权重全开源。
一句话看懂设计

沿三个方向
扩展信息流动

序列长度 · KDAKimi Delta Attention 做高效长序列混合，周期性穿插 Gated MLA 保住全局交互。
网络深度 · AttnRes注意力残差，让每一层都能选择性地回看此前所有层的表征，信息不再只能逐层往上传。
模型宽度 · LatentMoE896 个路由专家、每 token 只激活 16 个，在紧凑潜空间里算，稀疏度 56。
三招合起来，相比 Kimi K2，整体扩展效率提升约 2.5 倍。
架构长什么样

3×KDA + 1×MLA
逐 block 堆

每个 block 是「3 个 KDA 层 + 1 个 Gated MLA 层」，一路重复到底，末尾再补一个 MLA 保证最后一层做全局注意力。每个注意力层都挂一个 Stable LatentMoE 前馈网络。输入端有一条原生视觉通路：MoonViT-V2 编码图像/视频，投影器送进共享 embedding。优化器用 Per-Head Muon，逐头正交化让各注意力头学习更均衡。
token 混合 · KDA

线性注意力，
但更稳更快

KDA 用一个缩放 sigmoid 给对数衰减设了下界（gmin=−5），保留因子不会掉到没边。好处很实在：有限的衰减范围让对角、非对角块都能走稠密 Tensor Core 矩阵乘，省掉了单独的对角计算路径。输出门也从低秩升级成输入相关的全秩投影。位置信息由 KDA 的递推门控隐式编码（NoPE），所以不用改 RoPE 就能直接外推到 100 万 token。
layer 混合 · AttnRes

让深层
看得见浅层

普通网络里，信息只能一层层往上传，深了就容易糊。AttnRes 用可学习的伪查询，对 embedding 和此前各 block 的输出算注意力权重，每一层都能选择性读取历史层。为了不爆显存，做了分块：把层分成 N 个 block，只在 block 级表征上做完整注意力，开销从 O(Ld) 降到 O(Nd)。K3 分成 8 个 block、每 12 层，N≈8 就能拿回大部分收益。
channel 混合 · Stable LatentMoE

896 个专家，
只叫醒 16 个

896 → 16
路由专家总数 → 每 token 激活数，稀疏度 56，另有 2 个全宽共享专家
专家们在一个紧凑潜空间里算（宽度 ℓ），聚合后加 RMSNorm 稳住尺度。激活函数换成 SiTU-GLU（β1=4/β2=25），给门和上分支都做平滑封顶，既留住局部响应又不让数值炸。负载均衡用 Quantile Balancing，无辅助损失，靠专家偏置调派发，不动混合权重。
原生视觉 · MoonViT-V2

视觉编码器
从零训，不抄 SigLIP

以前（包括 K2.5）都拿 SigLIP 这类对比预训练模型来初始化视觉编码器，图个起跑优势。K3 反着来：从零用 next-token prediction 训。原因是稳定性——SigLIP 初始化接进 LLM 联合优化时梯度老尖峰，从零训的 MoonViT-V2 全程稳，而且效果追平 SigLIP 基线，那就没必要背这个包袱。
编码器是 27 层 ViT、约 0.4B，RMSNorm、去掉所有偏置；图像视频共享参数，注意力拆成帧内空间 + 帧间时间两趟。投影前用 2×2 pixel-shuffle 把视觉 token 砍到 1/4，3584×3584 的大图在 1M 上下文里也吃得下。
预训练

原生多模态 +
渐进长上下文

语言和视觉从第一步就一起训，图文 token 在同一个 next-token prediction 目标里交错，不搞事后对齐。上下文长度按课程渐进扩：预训练阶段 8K→64K，冷却阶段 256K→1M，把最烧钱的超长序列计算压在一小段预算里，既省又能逐步学会远程依赖。专门做了扩展律研究重调超参，OOD 验证坐实了 2.5× 效率。
后训练

冷启 → 三域 RL
→ 多教师蒸馏

SFT 先用领域专精模型合成轨迹、多阶段校验做冷启动，全程用 XTML 模板序列化复杂智能体轨迹；从 SFT 起就上 QAT（权重 MXFP4 / 激活 MXFP8）。然后在通用 / 智能体 / 代码三大领域做 RL，横跨多个推理强度档，训练「推理→行动→观察→验证→适应」这个通用循环，常常跨几百上千次工具调用、累计几百万 token。最后用多教师在策略蒸馏把各路专精策略并进一个统一模型。
智能体 RL 环境

白盒 harness，
不给单一脚手架惯坏

只用一套固定 harness 训，模型会过拟合到某种工具 schema 和交互习惯。K3 把 harness 拆成可配置、可组合的模块——工具接口、系统提示、上下文管理、技能、记忆、子智能体，能拼出主流 harness、也能拼出全新的。RL 时按任务动态换配置，逼模型见足够多样的组合。
