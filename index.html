K3 是什么
"把预训练底座扩到 3T 级参数，同时在 100 万上下文上扩展推理强度与长程交互，两条扩展轴一起推向前沿。"
—— 开放前沿智能：整体落后最强闭源（Fable 5 / GPT-5.6 Sol），稳定领先其余开源与闭源模型
核心思路

沿三个方向扩展信息流动

序列长度
KDA（Kimi Delta Attention）高效长序列混合，周期性 Gated MLA 保全局交互。
网络深度
AttnRes（注意力残差）让每层选择性关注此前所有层的表征。
模型宽度
Stable LatentMoE：896 路由专家、每 token 激活 16 个，潜空间内稀疏运算。
合起来相比 Kimi K2 带来约 2.5× 的整体扩展效率提升。
架构总览（图 2）

3×KDA + 1×MLA 逐 block 堆叠

·
每个 block 含 3 个 KDA 层 + 1 个 Gated MLA 层（3:1 混合），主干末尾再加一个 MLA 层保证最后一层做全局注意力。
·
每个注意力层都配一个 Stable LatentMoE 前馈网络。
·
输入端带原生视觉通路：MoonViT-V2 编码图像/视频 → 轻量投影器进共享 embedding 空间。
·
优化器用 Per-Head Muon（逐头正交化）。
token 混合 · KDA

Kimi Delta Attention

01
线性注意力，用缩放 sigmoid 给对数衰减设下界（gmin=−5），保留因子有下界。
02
有限的衰减范围让对角与非对角 tile 都能走稠密 Tensor Core 矩阵乘，消除对角计算路径。
03
输出门从低秩改为输入相关的全秩投影；穿插的 NoPE Gated MLA 提供无限制的全局内容交互。
位置信息由 KDA 的递推门控隐式编码（NoPE），无需 RoPE 重缩放即可外推到 1M。
layer 混合 · AttnRes

注意力残差：跨深度选择性信息流

·
用可学习伪查询对 embedding 与此前各 block 输出导出注意力权重，让每层选择性读取历史层。
·
分块 AttnRes：把 L 层分成 N 个 block，只在 block 级表征上做完整注意力，显存/通信从 O(Ld) 降到 O(Nd)。
·
K3 分成 8 个 block、每 12 层（含 embedding 共 9 个 block），N≈8 即恢复大部分收益。

原生视觉 · MoonViT-V2

从零 NTP 训练，不用 SigLIP 初始化

为什么从零
SigLIP 初始化接进 LLM 联合优化不稳定（梯度尖峰）；从零 NTP 全程稳定，且效果追平 SigLIP 基线。
编码器
27 层 ViT、约 0.4B，RMSNorm、去偏置；图像/视频共享参数，空间+时间两趟注意力。
省 token
2×2 pixel-shuffle 把视觉 token 减到 1/4，3584×3584 输入在 1M 上下文内可负担。
预训练

原生多模态 + 渐进式长上下文

·
语言与视觉从一开始就联合优化，token 在单一 next-token prediction 目标内交错。
·
四阶段上下文课程：预训练 8K→64K，冷却阶段 256K→1M，把昂贵的长序列计算集中在小部分预算内。
·
专门扩展律研究重调超参，OOD 验证显示合起来 2.5× 扩展效率。
后训练

SFT 冷启 → 三域 RL → 多教师蒸馏

·
SFT 用领域专精模型合成轨迹 + 多阶段校验，XTML 模板序列化；从 SFT 起就 QAT（权重 MXFP4 / 激活 MXFP8）。
·
在通用 / 智能体 / 代码三域做 RL，横跨多个推理强度档位，训练"推理→行动→观察→验证→适应"循环。
·
领域与强度专精策略通过多教师在策略蒸馏整合进统一模型；EAGLE-3 draft 做投机解码。
智能体 RL 环境

统一白盒 harness，拒绝过拟合单一脚手架

把智能体 harness 拆成可配置、可组合的模块：工具接口、系统提示、上下文管理、技能、记忆、子智能体。
Kimi CodeClaude CodeCodexOpenClawHermes可组合出全新 harness
RL 时为不同任务组动态构造不同 harness 配置，让模型见足够多样的组合，训出更通用的智能体。
基础设施

撑起 2.8T 训练的系统栈

KDA 协同设计
FlashKDA（CUTLASS chunkwise kernel）+ KDA 上下文并行（KCP）。
并行 & 显存
MoonEP 完美均衡专家并行 + Pipeline ZeRO-2 + P2P Muon 正交化。
百万 token Agent RL
AgentENV：Firecracker microVM 沙箱，133ms checkpoint / 49ms resume，累计 5100 万+ 沙箱。
部署侧：外部 KV 缓存池、KDA-aware 前缀缓存、WarpDecode MoE kernel、缓存亲和 + 预算准入调度。
